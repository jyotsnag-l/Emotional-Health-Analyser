# Emotional Health Analyzer

A web-based application designed to help users assess their emotional well-being through an interactive quiz format. This tool provides personalized insights and practical tips for maintaining mental health.

## 🌟 Features

- **Interactive Quiz**: Answer questions on a 5-point scale (Never, Rarely, Sometimes, Often, Always)
- **Progress Tracking**: Visual progress bar to track quiz completion
- **Personalized Results**: Detailed analysis of emotional health status
- **Health Tips**: Curated tips for maintaining emotional well-being
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **User-Friendly Interface**: Clean, intuitive navigation and design

## 🛠️ Technologies Used

- **HTML5**: Structure and content
- **CSS3**: Styling and responsive design
- **JavaScript**: Interactive functionality and quiz logic
- **Google Fonts**: Poppins font family for modern typography

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software installation required

### Installation

1. **Clone or Download** the project files to your local machine
2. **Navigate** to the project directory
3. **Open** `index.html` in your web browser

That's it! The application runs entirely in the browser.

## 📖 Usage

1. **Start**: Click "Start Analyzer" on the homepage
2. **Answer Questions**: Respond to each question using the 5-point scale
3. **Navigate**: Use "Previous" and "Next" buttons to move through questions
4. **Submit**: Click "Submit" when you've answered all questions
5. **View Results**: See your emotional health analysis and recommendations
6. **Get Tips**: Access additional mental health tips and resources
